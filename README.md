# Offline Customer Support Chatbot

A privacy-first e-commerce chatbot built using Ollama and Llama 3.2 3B. This project demonstrates local LLM deployment, prompt engineering (Zero-Shot vs. One-Shot), and performance evaluation.

## Project Structure
- `chatbot.py`: Main script to interact with the Ollama API.
- `prompts/`: Contains prompt templates for zero-shot and one-shot prompting.
- `eval/`: Contains evaluation results and scores.
- `setup.md`: Detailed setup and installation instructions.
- `report.md`: Analysis of results and findings.

## Key Features
- **Privacy-First**: All data stays on your local machine.
- **Cost-Effective**: No API costs associated with third-party LLM providers.
- **Comparative Analysis**: Compares zero-shot vs. one-shot prompting techniques.
